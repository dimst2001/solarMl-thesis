 
solarMLthesis/
├── .gitignore                    # Excludes myenv/, data/ binary files, *.csv, *.parquet, and IDE caches from Git tracking
├── README.md                     # Project overview, system metadata, setup instructions, and execution steps for reproducibility
├── requirements.txt              # Explicit dependency list with pinned package versions (Pandas, PyArrow, XGBoost, etc.)
├── setup.py                      # Package installation script to allow `pip install -e .` for modular `src/` imports
│
├── configs/                      # Declarative configuration parameters (YAML)
│   ├── system_config.yaml        # System-specific metadata: lat/lon coordinates, capacity thresholds, and sensor name mappings
│   └── train_config.yaml         # Training parameters: feature lists, window lengths, lag steps, and hyperparameter grids
│
├── data/                         # Project datasets (Excluded from Git tracking via .gitignore)
│   ├── raw/                      # Unmodified daily Apache Parquet files downloaded directly from AWS S3 (oedi-data-lake)
│   ├── processed/                # Wide-format daily files transformed from long sensor schema via `transform_data.py`
│   ├── cleaned/                  # Cleaned per-system CSV/Parquet files generated by `clean_systems.py` (sentinels removed, units fixed)
│   └── features/                 # Final engineered matrices containing solar geometry, temporal lags, and rolling aggregations
│
├── src/                          # Core Python source package for pipeline execution
│   ├── __init__.py               # Package initialization exposing top-level path constants (`DATA_DIR`, `CONFIG_DIR`, `SRC_DIR`)
│   │
│   ├── utils/                    # Shared helper utilities across scripts and notebooks
│   │   ├── __init__.py           # Subpackage initializer exposing IO and metric functions
│   │   ├── io.py                 # File reading/writing procedures with type downcasting (`float64` -> `float32`) for memory optimization
│   │   └── metrics.py            # Mathematical functions for RMSE, MAE, MBE, R², nRMSE, and nMAE calculation
│   │
│   ├── data/                     # Data processing, cleaning, and feature construction pipelines
│   │   ├── __init__.py           # Subpackage initializer exposing preprocessing functions
│   │   ├── transform_data.py     # Script executing long-to-wide daily Parquet conversion
│   │   ├── merge_systems.py      # Script executing temporal concatenation of daily files into consolidated system files
│   │   ├── cleaning.py           # Reusable cleaning logic (unit conversions, sentinel removal, physical bound clipping)
│   │   └── feature_engineering.py# Computes astronomical solar position (pvlib), cyclic time signals, lags, and rolling window stats
│   │
│   ├── models/                   # Machine learning architectures and temporal validation
│   │   ├── __init__.py           # Subpackage initializer exposing model interfaces
│   │   ├── baselines.py          # Naive 24-hour persistence and statistical reference models for benchmark comparison
│   │   ├── tree_models.py        # Model wrappers and training routines for XGBoost, LightGBM, and Random Forest
│   │   └── evaluator.py          # Purged Group Time-Series Split cross-validation logic preventing temporal data leakage
│   │
│   └── visualization/            # Thesis and manuscript graphic generators
│       ├── __init__.py           # Subpackage initializer exposing plotting tools
│       └── plots.py              # Script generating IEEE-formatted actual vs. predicted curves, residual distributions, and feature importances
│
├── notebooks/                    # Jupyter notebooks for exploratory data analysis and thesis evidence generation
│   ├── 01_eda_data_quality.ipynb                # Initial sensor distributions, missing value counts, and outlier verification
│   ├── 02_feature_engineering_validation.ipynb  # Verification of calculated solar geometry parameters and lag feature correlation
│   ├── 03_baseline_benchmarks.ipynb             # Execution and evaluation of statistical persistence models
│   └── 04_model_evaluation_and_tables.ipynb    # Tree model training, cross-validation scoring, and metric comparison table exports
│
├── tests/                        # Automated unit tests validating data integrity and pipeline logic
│   ├── test_cleaning.py          # Tests sentinel replacement, physical boundary clipping, and unit conversion correctness
│   └── test_features.py          # Tests lag alignment, non-leaking rolling window calculations, and time series split bounds
│
├── artifacts/                    # Generated execution outputs
│   ├── models/                   # Serialized model binary weights (`.json`, `.pkl`, `.joblib`) (Excluded from Git)
│   └── metrics/                  # Evaluation summaries stored as JSON files for experiment tracking
│
└── docs/                         # Manuscript export files
    └── tables/                   # Generated Markdown and LaTeX metric summary tables ready for direct thesis inclusion
